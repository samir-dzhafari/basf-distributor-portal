# Сценарий демонстрации — 10 минут

Подготовка: `npm run dev`, открыть http://localhost:5173, меню пользователя → «Сбросить демо-данные».
Вход — плитками «Войти без пароля» на экране входа (или пароль `Demo2027`). Ссылки между шагами работают в одном окне; роли переключаются выходом.

| Время | Роль | Что показываем | Что сказать |
|---|---|---|---|
| 0:00–1:00 | — | Экран входа, плитки ролей, «Забыли пароль?», письмо-приглашение | Вход по логину/паролю; демо-плитки только для показа. Письма на демо показываются на экране. |
| 1:00–3:30 | Клиент (Пётр Иванов) | «Создать заказ»: грузополучатель → регион и тип бизнеса → оплата/поставка/дата → приложение → сводка → продукты. Ввести количество не кратное упаковке — подсказка ближайшего значения. Суммы с НДС. «Отправить». | Мастер по шагам, ошибки по-человечески, черновик сохраняется. |
| 3:30–4:30 | Клиент | «Мои заказы»: поиск, фильтры, карточка заказа (позиции, комментарии, история), отмена с комментарием, колокольчик | Клиент видит заказы всего юрлица; цены справочные, остатков нет. |
| 4:30–6:30 | Одобряющий менеджер | «Одобрение»: счётчик в меню, очередь, корректировка количества/удаление позиции, отклонение (комментарий обязателен), одобрение | Добавлять позиции нельзя. Создавший заказ не может одобрить его сам (настройка). |
| 6:30–7:30 | Администратор | «Обмен с 1С»: заказ идёт «Передан → Принят → Выполнен»; ошибка передачи и «Повторить» | Эмуляция 1С: номер, статусы, ошибки обмена. |
| 7:30–8:30 | Администратор | «Сотрудники» → карточка → вкладка «Что видит сотрудник и почему»; «Роли» — конструктор прав | Видимость = объединение клиентов, регионов, типов бизнеса, подчинённых и приложений; всегда можно объяснить, почему заказ виден. |
| 8:30–9:30 | Администратор | «Клиенты» (карточка, импорт из Excel), «Продукты» (закрытие вместо удаления, цены с историей), «Справочники» | Коды 1С везде видны; массовая загрузка с отчётом об ошибках. |
| 9:30–10:00 | Администратор | «Рассылка» (просмотр письма), «Журнал действий», «Настройки»; телефонный размер экрана для заказа клиента | Всё действие аудируется; клиентская часть адаптивна. |

Запасные ходы: «Справка» в меню пользователя; «Сбросить демо-данные» — вернуть исходное состояние.
